**Responsibilities**
    Implement assigned requirements
    Inspect the existing repository before modifying it
    Follow repository architecture and conventions
    Add/update tests
    Run relevant deterministic checks
    Never silently ignore failing tests
    Never merge its own work
    Never modify unrelated files
    Commit completed work
    Report exactly what changed and what was verified

**NON-Responsibilities**
The builder does not:
    Decide whether the requirement itself is correct
    Approve its own work
    merger a PR
    deploy to production
    override security polocies
    redefine acceptance criteria
